# スマホの写真もOK！どこでも個人情報削除ツール

スマホ・パソコンのブラウザで、JPEG / PNG 画像から位置情報（GPS）・撮影機器・撮影日時などのメタデータを削除する Web ツールです。

- **画像はサーバーに送信されません。** すべてブラウザ内で処理します。
- **JPEG は再圧縮しません。** メタデータ部分だけを取り除くため、画質は変わりません。
- **ダウンロードすると元データを破棄します。** 画面にも破棄したことを表示します。
- サーバー・データベース不要の静的ファイル（`index.html` ほか）だけで動きます。運用費用はかかりません。

## 使い方

1. 公開URLを開き、画像をドラッグ＆ドロップ（またはクリックして選択）します。複数枚可。
2. 「検出 → 削除済み」の表示を確認します。
3. 「保存して破棄」を押すと、`元の名前_clean.jpg` / `元の名前_clean.png` として保存され、元データがメモリから消えます。

## Windows標準機能との違い

Windows には、プロパティ → 詳細 →「プロパティや個人情報を削除」という標準機能があります。

| | Windows標準 | このツール |
|---|---|---|
| 使える端末 | Windowsパソコンのみ | スマホ・タブレット・Mac・Windows（ブラウザがあれば可） |
| 削除する項目 | 自分で選ぶ（または「可能なすべて」） | 検出した項目を表示し、自動ですべて削除 |
| 削除結果の確認 | 削除後に自分で詳細タブを確認 | 「検出 → 削除済み」を画面に表示 |
| 元の写真 | 「元ファイルから削除」か「コピーを作成」 | 元は変更せず、削除済みコピーを保存 |
| データの扱い | パソコン内で処理 | 端末内で処理。保存時に元データをメモリから破棄 |

Windowsのパソコンだけで使う場合は、標準機能でも手軽に削除できます。

## 削除されるもの / 残るもの

| 形式 | 削除する | 残す |
|---|---|---|
| JPEG | EXIF（GPS・機器・日時）、XMP、IPTC、コメント、埋め込みサムネイル、画像末尾の付加データ | 画像データ本体、色情報（ICC）、**向き（回転）情報のみ** |
| PNG | tEXt / zTXt / iTXt（XMP含む）、eXIf、tIME | 画像データ、色情報、その他の描画に必要な情報 |

向き情報を残すのは、消すと写真が横倒しで表示されるためです。位置や機器の情報は含みません。

### 消えないもの

画像に**写り込んだ内容**（看板、表札、車のナンバー、顔、窓からの景色など）は消えません。公開前に目視で確認してください。

## 仕組み（プライバシー）

- 画像は `File` → メモリ上の `ArrayBuffer` として読み込み、バイト列を直接処理します。
- ページに Content-Security-Policy（`connect-src 'none'`）を設定し、**ブラウザが外部へ通信すること自体を禁止**しています。
- Cookie、ローカルストレージ、アクセス解析、広告は使用していません。
- 「保存して破棄」「保存せずに全て破棄」で、元画像と処理済み画像への参照をすべて手放します。ページを閉じても同様にすべて消えます。

詳細は [privacy.html](privacy.html) を参照してください。

## 公開方法（GitHub Pages）

1. 公開（Public）リポジトリを作成し、上記ファイルをアップロードします。
2. Settings → Pages → Source を「Deploy from a branch」、Branch を `main` / `(root)` にして保存します。
3. 表示された `https://<ユーザー名>.github.io/<リポジトリ名>/` が公開URLです。

## 制限事項

- 対応形式は JPEG / PNG のみです（WebP・HEIC・GIF などは未対応）。
- 非常に大きな画像（数百MB）や多数の同時処理は、端末のメモリ不足で失敗することがあります。
- JPEG の仕様外の独自形式（一部メーカーの特殊な写真形式など）では、想定どおりに処理できない場合があります。**重要な用途では、処理後のファイルをメタデータ確認ツールで確認することをおすすめします。**
- 本ツールは現状有姿で提供され、完全な匿名化を保証するものではありません。

## 開発メモ

- 変換ロジックは `index.html` 内の `// ==CORE==` 〜 `// ==/CORE==` の間に集約しています（`stripJpeg` / `stripPng`）。
- ビルド工程・外部ライブラリはありません。ブラウザで `index.html` を開くだけで動作します。
